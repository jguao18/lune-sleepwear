# 🌙 Lune Sleepwear

> **"Pijamas que abrazan tu piel y consienten tus noches."**  
> Tienda web oficial y catálogo interactivo de Lune Sleepwear en tonos **lila pastel** y **amarillo mantequilla**.

---

## ✨ Características de la Web

* **Catálogo de Kits & Combos:** Pijamas de dos piezas (short y pantalón largo) y batas kimono de satín sedoso con selector de tallas (S, M, L).
* **Experiencia Sensorial de Unboxing:** Presentación del empaque boutique, aroma relajante y tarjeta dedicatoria.
* **Simulador Interactivo de Instagram (`@lune.sleepwear`):** Feed visual con posts interactivos donde puedes tocar cada publicación para ver el audio, guión de grabación para celular y pie de foto listo.
* **Carrito de Compras y Pedido Directo a WhatsApp:** Genera el mensaje de compra formateado listo para enviar.

---

## 🚀 Despliegue en Vivo con GitHub Pages

Para ver la web en internet y compartirla:
1. En este repositorio ve a **Settings > Pages**.
2. En **Build and deployment > Source**, selecciona **Deploy from a branch**.
3. En **Branch**, selecciona `main` / `(root)` y haz clic en **Save**.
4. ¡Tu tienda estará online en: **`https://jguao18.github.io/lune-sleepwear/`**! 🌐✨

# 🌙 Lune Sleepwear

> **"Pijamas que abrazan tu piel y consienten tus noches."**  
> Marca boutique de pijamas y rituales de descanso en tonos **lila pastel** y **amarillo mantequilla**.

---

## ✨ Contenido del Repositorio

* **`index.html`**: Tienda web interactiva oficial, catálogo de combos con tallas (S, M, L), checkout por WhatsApp, experiencia sensorial de unboxing y simulador interactivo del feed de Instagram.
* **`SIMULADOR_COSTOS_LUNE.html`**: Simulador web de rentabilidad y márgenes para calcular los precios de venta de cada combo.
* **`PLAYBOOK_CONTENIDO_LUNE.md`**: Guía y guiones de contenido para Instagram y TikTok (15 ideas listas para grabar con el celular, audios y copys).
* **`PLAN_MAESTRO_LUNE.md`**: Estrategia de negocio, proveedores (Cali/Cauca vs. Shein) y empaque sensorial.
* **`APPS_SCRIPT_BOT_TELEGRAM.js`**: Automatización en Google Apps Script para conectar Google Sheets con un bot de Telegram y registrar pedidos desde el móvil.

---

## 🚀 Despliegue en Vivo con GitHub Pages
Este repositorio está listo para ser publicado en la web a través de **GitHub Pages**:
1. Ve a **Settings > Pages** en este repositorio.
2. En **Build and deployment > Branch**, selecciona `main` y guarda.
3. Tu tienda estará disponible en vivo en: `https://jguao18.github.io/lune-sleepwear/`
